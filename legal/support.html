Questions fréquentes

Comment fonctionne Kinetic ?

Swipez à droite les mangas qui vous intéressent, à gauche ceux qui ne vous tentent pas. Vos choix sont enregistrés pour affiner les suggestions.

Puis-je utiliser l'app sans créer de compte ?

Oui, avec le mode invité. Vos données restent liées à ce compte anonyme ; si vous supprimez l'app sans créer de compte, elles ne pourront pas être récupérées.

Comment supprimer mon compte ?

Dans l'app : Profil → Réglages → Supprimer mon compte. La suppression est immédiate et définitive, pour les comptes classiques comme pour les comptes invités.

Comment désactiver les notifications ?

Réglages d'iOS → Notifications → Kinetic.

D'où viennent les informations sur les œuvres ?

Les titres, couvertures et résumés proviennent d'AniList.
